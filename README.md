# پنل SIEM

پنل راست‌به‌چپ React برای مرکز عملیات امنیت. نمای کلی، نمودارها، دریافت گروهی، جست‌وجو و فیلتر لاگ، قواعد تشخیص، هشدارها، پرونده‌ها، تحلیل هوشمند و وضعیت سامانه در منوی پنل قرار دارند. تم روشن و تیره با انتخاب کاربر در مرورگر ذخیره می‌شود.

## اجرای محلی

پیش‌نیاز Node.js 22.12 یا جدیدتر است.

```sh
npm ci
npm run dev
```

پنل روی `http://localhost:5173` اجرا می‌شود. برای تست و ساخت نسخهٔ استاتیک از فرمان‌های زیر استفاده کنید.

```sh
npm test
npm run build
```

خروجی build در `dist/` قرار دارد. داده‌های ماک با بارگیری صفحه بازنشانی می‌شوند. ثبت گروه، وضعیت پرونده یا هشدار و فعال‌سازی قاعده فقط بر داده‌های همان نشست اثر می‌گذارند.

## قرارداد بک‌اند

منو از پاسخ ماک `GET /api/v1/system/navigation` ساخته می‌شود. ترتیب شناسه‌ها و تگ‌ها با بک‌اند SIEM مشترک است. پنل از همان نام مسیر، پارامتر، فیلدهای JSON و وضعیت‌ها استفاده می‌کند.

| نما | مسیرهای مورد استفاده (پیشوند `/api/v1`) |
| --- | --- |
| نمای کلی | `GET /overview`، `GET /dashboard/charts`، `GET /search/events` |
| دریافت و پردازش | `POST /ingestion/batches`، `GET /ingestion/batches/{batch_id}`، `GET /logs` |
| رویدادها | `GET /search/events` |
| قواعد، هشدارها و رخدادها | `GET /detections/rules`، `GET /alerts`، `GET /incidents` و `PATCH` مسیرهای شناسه‌دار |
| تحلیل هوشمند | `GET /datasets/folders`، `GET /normalization/records`، `GET /standardization/records`، `GET /system/status` |
| سامانه | `GET /system/settings`، `GET /system/status`، `GET /health` |

همهٔ درخواست‌ها از `src/api.js` عبور می‌کنند. انتقال پیش‌فرض `mockRequest` است و API واقعی در این نسخه فعال نیست. برای اتصال بعدی می‌توان نمونهٔ API را با `createApi({ request: fetch })` ساخت. در توسعه، Vite مسیر `/api/v1` را به FastAPI روی `127.0.0.1:8000` پراکسی می‌کند. در استقرار واقعی همان مسیر را در مبدأ پنل به بک‌اند هدایت کنید. قرارداد منو و عملیات در [بک‌اند SIEM](https://github.com/hosseini-milad/siem) قرار دارد.

## کاوش داده‌ها

«کاوش داده‌ها» داده‌های شبکه و لاگ‌های چند روز را با صفحه‌بندی نمایش می‌دهد. روز بر اساس منطقهٔ زمانی مرورگر تفسیر می‌شود. «همهٔ روزها» محدودهٔ تاریخ را برمی‌دارد. فیلترهای پیشرفته با هم اعمال می‌شوند. جزئیات هر رکورد شامل نسخهٔ خام و در صورت وجود نسخهٔ نرمال‌شده و امتیاز مخاطرهٔ نمونه است.

مسیر `GET /api/v1/explorer/records` فعلاً فقط در لایهٔ ماک پیاده شده است. اتصال این صفحه به FastAPI به یک مسیر تجمیعی یا لایهٔ تطبیق نیاز دارد. شروع بازه شامل و پایان آن انحصاری است.
